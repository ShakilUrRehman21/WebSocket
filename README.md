#  WebSocket – Real-Time Communication Platform

A basic real-time communication platform built using **Spring Boot** and **WebSockets**.
This project demonstrates how to enable bidirectional, real-time messaging between server and clients.

---

##  Features

*  Real-time message exchange
*  WebSocket-based communication
*  Low-latency server-client interaction
*  Multiple clients can connect simultaneously
*  STOMP messaging support (if used)

---

##  Tech Stack

* **Java**
* **Spring Boot**
* **Spring WebSocket**
* **STOMP (if implemented)**
* **HTML, CSS, JavaScript**
* **Maven**

---

##  Run Locally

### 1️ Clone the repository

```bash
git clone https://github.com/ShakilUrRehman21/WebSocket.git
cd WebSocket
```

### 2️ Run the application

```bash
mvn spring-boot:run
```

Or run the main class from your IDE.

### 3️ Open in browser

```
http://localhost:8080
```
